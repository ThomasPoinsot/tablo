# Tablo

Petite appli pour réviser le calcul mental (CE1 et plus) :

- tables d'addition ;
- doubles et moitiés ;
- tables de multiplication.

Les calculs arrivent un par un avec un sablier : une note sur 20, et des points selon la vitesse de réponse.

**Fonctionnalités** : profils enfants avec avatar et thème (Lagon, Bonbon, Arcade), mode intelligent qui cible les calculs mal acquis, carte de progression par table, réponse à la voix (Chrome, Edge ou Safari), export et import de la sauvegarde.

## Utilisation

- **En ligne** : <https://thomaspoinsot.github.io/tablo/>. Sur téléphone, utiliser « Ajouter à l'écran d'accueil ».
- **En local** : ouvrir `tablo.html` dans un navigateur. Ce fichier contient toute l'appli.

Les profils et les résultats sont enregistrés uniquement dans le navigateur de chaque appareil. Rien n'est envoyé sur un serveur.
